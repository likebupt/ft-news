**Apple**
- Apple introduced a distillation method for discrete flow-matching text models that uses the full multi-step denoising trajectory as supervision, enabling a student model to generate in far fewer steps. For finetuning/post-training, it points to a practical way to compress slow iterative generators into deployable students while preserving trajectory-level learning signals. [Read more](https://machinelearning.apple.com/research/trajectory-teacher-flow-matching)
- Apple proposed **DACA-GRPO**, an RL method for diffusion language models that assigns credit based on denoising-step importance rather than treating all steps equally. This matters for finetuning because it could make RL-style post-training for diffusion/non-autoregressive LMs less noisy and more sample-efficient. [Read more](https://machinelearning.apple.com/research/denoising-aware-credit-assignment)
- Apple studied how value induction during post-training changes LLM behavior when models are trained on text expressing traits like empathy, curiosity, and honesty. For finetuning, the key implication is that alignment/value datasets can reshape model behavior broadly, so data selection affects far more than narrow task performance. [Read more](https://machinelearning.apple.com/research/value-induction-llm-behaviour)

**OpenAI**
- OpenAI published a framework for tracking, investigating, and disclosing model misalignment, along with six example reports of concerning behavior. For finetuning teams, it offers a useful structure for post-training evals, regression monitoring, and incident response when alignment updates cause unexpected failures. [Read more](https://openai.com/index/model-misalignment-reporting-framework)
- OpenAI showcased how Fyxer uses fine-tuning, memory, and real user feedback to build an email assistant that drafts in each user’s voice. It matters as a concrete example of personalized post-training paired with feedback loops to improve trust, consistency, and product usefulness. [Read more](https://openai.com/index/fyxer)
